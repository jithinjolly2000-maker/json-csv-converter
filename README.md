Paste on the left, converted output appears on the right as you type — then copy it or feed it back in with **Use output as input**.

## ✨ Features

- **JSON → CSV** — nested objects flattened with dotted keys (`contact.email`); headers unioned across all rows
- **CSV → JSON** — array of objects, with sensible **type coercion** (numbers, booleans, null) that never mangles a value it can't safely convert
- Proper CSV quoting (commas, quotes, newlines inside fields)
- One-click **copy** and a **swap** button to chain conversions
- Clear ✓/✗ status with the parse error message when input is invalid

## 🔒 Private by design

Everything runs **100% in your browser** — nothing is uploaded.

## 🧰 Tech

- **Vanilla HTML / CSS / JavaScript** — no frameworks, no dependencies, one `index.html`
- Hosted free on **GitHub Pages**

## ▶️ Run locally

```bash
start index.html      # Windows — no build step
```
